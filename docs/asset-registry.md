# Asset registry

Reviewed 2026-07-18. This registry covers every first-party visual asset committed to the Scout
source tree. It is a provenance and permitted-use ledger, not a trademark registration or a licence
grant. The repository owner is the approval owner for all entries.

## Ownership and review policy

- **Origin and owner:** Scout design work created for this repository, except the audit screenshots,
  which were generated by Scout's automated visual-smoke fixture from fictional Northstar Retail
  data. The Scout project owner asserts ownership of these assets under the repository `LICENSE`.
- **Permitted surfaces:** Scout product, packaging, plugin, repository documentation, and project
  presentation surfaces as narrowed in the tables below. Third-party resale or standalone reuse is
  not granted.
- **Approval:** approved for the listed surfaces on 2026-07-18 by the repository owner.
- **Expiry:** no fixed expiry. Re-review is required after a brand redesign, ownership transfer,
  material asset edit, customer-data substitution, or change in distribution terms.
- **Integrity:** checksums are SHA-256 over the exact committed bytes. Any content change requires an
  updated checksum and review date.

## Variant status

The current tree includes a vector source, raster app sizes, in-app scale variants, and plugin
variants. Dedicated light, dark, monochrome, and optically corrected small-size artwork remains a
binary-release product-quality gate; it does not block public inspection of this source tree. Scout
does not ship a third-party vendor-logo wall.
