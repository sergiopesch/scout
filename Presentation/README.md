# Scout HTML presentation

Open `index.html` in a modern browser. The deck is self-contained except for project-local Scout logo and product screenshot assets, referenced by relative path.

## Presenter controls

- `→`, `Space`, or `Page Down`: next slide
- `←` or `Page Up`: previous slide
- `Home` / `End`: first / last slide
- `F`: enter or exit fullscreen
- `N`: toggle private speaker notes
- `O`: open the slide overview

Slide 7 contains a scripted discovery simulation. Slide 12 contains an interactive current-state / proposed-state simulation. Northstar Retail, its participants, statements, metrics, and proposed proof of value are fictional and exist only to explain the product workflow; they are not customer evidence or operational test results.

The deck is a product narrative, not a capability certification. Current operational evidence and
remaining limits are recorded in [`docs/product-readiness.md`](../docs/product-readiness.md) and
[`docs/verification.md`](../docs/verification.md). Enterprise methods and platform names are optional
classification vocabulary governed by [`docs/enterprise-context.md`](../docs/enterprise-context.md),
never facts about the fictional scenario or a real customer.

For the cleanest live delivery, open the deck from this folder and enter fullscreen before presenting.
